# SIGAB v4.0.23 — 2026-07-09

## Qué cambió
Cierra el punto 1 del backlog de `docs/DESIGN-SYSTEM-V4.md`: los tokens CSS
del tema `[data-theme="green"]` (`sigab-frontend/src/index.css`) usaban el
verde SIGAH histórico en vez de la paleta Stitch oficial "Verde-Blanco IMSS"
definida como fuente de verdad del rediseño.

- `--sidebar-bg` / `--accent`: `#059669` → `#047857` (primary Stitch)
- `--accent-dark`: `#047857` → `#065F46` (secondary/dark Stitch)
- `--accent-light`: `#DCFCE7` → `#E0F0E9` (tertiary Stitch)
- `--content-bg`: `#F8FAFC` → `#F8FAF9` (neutral Stitch)
- `--bottom-nav-active`: `#059669` → `#047857`
- El swatch y la etiqueta del selector de tema en `Header.jsx` se
  actualizaron a juego (`#047857`, "Verde-Blanco IMSS (claro)").

Los temas Azul IMSS, Oscuro y Glass no se tocaron. El tema `dark` conserva
`#059669` a propósito — es una paleta distinta, no candidata a
Verde-Blanco IMSS.

Este cambio no altera ningún componente ni lógica: solo valores hex en
variables CSS centralizadas, así que se propaga automáticamente a todo lo
que ya usa `var(--accent)` / `var(--content-bg)` / etc. sin tocar archivo
por archivo.

## Qué verificar
1. Cambiar el selector de tema (menú de usuario en `Header`) a
   "Verde-Blanco IMSS (claro)" y confirmar que sidebar, botón activo del
   bottom-nav (móvil) y acentos generales se ven en el verde correcto
   (`#047857`, ligeramente más oscuro que el `#059669` anterior — diferencia
   sutil, no un cambio de color radical).
2. El fondo de contenido en tema verde debe seguir viéndose blanco/casi
   blanco a simple vista (`#F8FAF9` vs `#F8FAFC` anterior).
3. Confirmar que los temas "Azul IMSS", "Oscuro" y "Glass" no cambiaron
   visualmente — solo se tocó el bloque `[data-theme="green"]`.
4. `npm run build` y `npx vitest run` verdes (verificado en este ciclo: 19
   tests, build en 6.37s).
