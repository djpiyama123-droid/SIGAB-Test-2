# v4.0.36 — Bugs de contraste en Dashboard (MaintenanceChart + AlertaBanner)

**Fecha**: 2026-07-11 · **Tipo**: patch · **Autor**: loop-thinkcentre

## Qué cambió

Se encontraron y corrigieron 2 bugs de contraste tema-claro/oscuro en el
Dashboard (`sigab-frontend/src/pages/Dashboard.jsx`), la pantalla más
visitada de la app. Ninguno de los barridos de contraste anteriores
(`grep text-white|text-black|bg-white`, luego la segunda pasada de tonos
claros `text-red-300|text-orange-300|text-yellow-300`) los había detectado.

Se encontraron comparando el estado actual de dos componentes contra
`86373f7`, un commit de barrido de contraste ya hecho en `feat/ui-cinematic`
el 2026-06-20 que nunca se portó a esta rama (`v4.0/piloto-clinica-1`
diverge de una base anterior a ese commit).

### 1. `components/charts/MaintenanceChart.jsx`
El tooltip de la gráfica "Mantenimientos Programados vs Completados" (recharts)
tenía `backgroundColor:'#0f172a'`/`borderColor:'#334155'` fijos, sin `color`,
`itemStyle` ni `labelStyle`. En temas claros (Verde-Blanco IMSS, Azul) esto
mostraba una caja de tooltip oscura flotando sobre un dashboard claro —
inconsistente con el resto de la app. Se migró a `var(--content-bg)`/
`var(--content-border)`/`var(--content-text)`, se agregaron `itemStyle`/
`labelStyle` explícitos y se cambió el cursor de hover a un gris neutro. Es
el mismo patrón que ya usa `DegradationChart.jsx` desde v4.0.17.

### 2. `components/AlertaBanner.jsx`
El banner de alertas rojas (arriba de los KPIs del Dashboard, cuando hay
alertas activas) tenía el texto del mensaje en `text-red-200` (rosa claro,
pensado para fondo oscuro) sobre `bg-red-900/30` — en temas claros esa
combinación pierde casi todo el contraste. Se migró el mensaje a
`var(--content-text)`, el subtítulo (equipo/serie) a `var(--content-muted)`,
y el ícono/prioridad a `text-red-600` (legible en ambos modos).

## Qué verificar

1. Dashboard en tema Verde-Blanco IMSS o Azul, con al menos una alerta
   activa: el texto del banner rojo debe leerse con claridad.
2. Dashboard en tema claro: pasar el mouse sobre una barra de "Mantenimientos
   Programados vs Completados" — el tooltip debe verse con fondo claro,
   consistente con el resto de la página.
3. Dashboard en tema oscuro (glass/dark): sin regresión visual — debe verse
   exactamente igual que antes.
4. `npm run build` y `npx vitest run` verdes (35 tests) — verificado en este
   ciclo.

## Cómo revertir

`git revert` del commit de esta versión sobre `v4.0/piloto-clinica-1`.
Cambio acotado a 2 archivos de frontend, solo colores/estilos (sin lógica de
negocio nueva) — revert seguro y sin dependencias.
