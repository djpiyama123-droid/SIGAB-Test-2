# SIGAB v4.0.21 — Recorte del bundle principal (iconos lucide-react)

**Fecha**: 2026-07-08 · **Tipo**: patch · **Autor**: loop-thinkcentre

## Qué cambió

El chunk principal de JavaScript (`index-*.js`), el que se descarga en
**toda** visita a la app —incluso antes de iniciar sesión—, pesaba
1,003 kB (202.76 kB comprimido). La causa: tres componentes usaban el
patrón `import * as Lucide from 'lucide-react'` seguido de acceso dinámico
(`Lucide[nombreDeIcono]`) para poder elegir el ícono a partir de un string:

- `components/Layout.jsx` (barra de navegación inferior, móvil)
- `components/Sidebar.jsx` (menú lateral de escritorio)
- `components/cards/StatusIndicator.jsx` (indicador de conexión SSE)

Ese patrón le impide a Rollup (el empaquetador) saber en tiempo de build qué
iconos se usan realmente, así que empaqueta la librería completa (~1600
iconos) dentro del chunk que la consume.

Se reemplazó por mapas estáticos con imports nombrados: `utils/navIcons.js`
(nuevo) para Sidebar/Layout, y un mapa local de 2 iconos dentro de
`StatusIndicator.jsx`. Mismo comportamiento visual, mismos iconos — solo
cambia cómo se resuelven en el bundle.

## Resultado medido

| Chunk | Antes | Después |
|---|---|---|
| `index-*.js` (siempre se descarga) | 1,003 kB / 202.76 kB gzip | 111 kB / 37.67 kB gzip |
| `Dashboard-*.js` (solo esa página) | 44 kB | 47 kB |

`npm run build` y `npx vitest run` verdes.

## Qué verificar

1. En cualquier página, el sidebar de escritorio y la barra inferior en
   móvil deben verse con los mismos iconos que antes.
2. Como superadmin, el enlace "Panel Admin" debe seguir mostrando el ícono
   de edificio.
3. En el Dashboard, el indicador de conexión (junto al título) debe seguir
   mostrando el ícono de wifi cuando hay conexión SSE activa.
4. Opcional (DevTools → Network, primera carga): `index-*.js` debe pesar
   ~111 kB en vez de ~1000 kB.

## Cómo revertir

`git revert` de este commit sobre `v4.0/piloto-clinica-1` + redeploy del
frontend. Es un cambio mecánico de imports (mismos componentes, mismos
props, mismo comportamiento), sin lógica de negocio ni llamadas a la API —
revert seguro, no requiere tocar la base de datos.

## Nota sobre la petición de Órdenes IMSS (prioridad de Gustavo)

Este ciclo se investigó primero el porteo del formato IMSS de Órdenes
(petición directa de Gustavo, 2026-07-08) antes de pasar a este cambio.
Hallazgo: el porteo ya está más avanzado de lo documentado — existe
`components/formatos/` integrado en `Ordenes.jsx`/`Formatos.jsx` que ya
cubre la mayoría de los campos. Cerrarlo por completo requiere trabajo en
`sigab-backend/` (el modelo SQLAlchemy y la whitelist del endpoint PUT no
persisten 3 de los 7 campos nuevos) — fuera del carril de este loop
(solo `sigab-frontend/`). Detalle completo en
`docs/cerebro/CONTEXTO-COMPARTIDO.md`, sección "Actualización 2026-07-08".
