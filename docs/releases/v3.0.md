## Resumen ejecutivo

Migración visual completa del frontend de tema oscuro (dark slate) a tema claro Verde-Blanco con identidad institucional IMSS. La lógica de negocio, los endpoints, el modelo de datos y los flujos clínicos NO se tocaron. **Cambio cosmético + sistema de variables CSS.**

Resultado:
- Fondo claro con tokens semánticos (`--content-bg`, `--content-surface`, `--content-text`, etc.).
- Sidebar azul/verde IMSS (configurable por tema).
- Contraste accesible WCAG AA en los 52 módulos migrados.
- 3 temas seleccionables: Verde SIGAH (default), Azul IMSS, Oscuro.
- 0 regresiones funcionales reportadas post-deploy.

## Alcance técnico

### Sistema de variables CSS

```css
:root[data-theme="green"] {
  --content-bg: #F8FAFC;
  --content-surface: #FFFFFF;
  --content-border: #E2E8F0;
  --content-text: #1E293B;
  --content-muted: #64748B;
  --accent: #047857;
  --accent-dark: #065F46;
  --accent-light: #E0F0E9;
  --sidebar-bg: #059669;
  --header-bg: #FFFFFF;
}
```

Tres temas disponibles en `ThemeContext`: `green` (default), `blue` (IMSS), `dark`. Persistencia en `localStorage`.

### Tabla de migración (contrato)

| Era oscura | Tema claro |
|---|---|
| `text-white` (contenido) | `text-[var(--content-text)]` |
| `text-slate-100/200` | `text-[var(--content-text)]` |
| `text-slate-300/400` | `text-[var(--content-muted)]` |
| `bg-slate-900/950` (página) | `bg-[var(--content-bg)]` |
| `bg-slate-800` (tarjeta/superficie/input) | `bg-[var(--content-surface)]` |
| `bg-slate-700` (hover/elevated) | `bg-[var(--content-bg)]` |
| `border-slate-700/800` | `border-[var(--content-border)]` |
| `#0f172a` / `#1e293b` (hex) | `var(--content-bg)` / `var(--content-surface)` |

### Excepciones (NO se migran — son intencionales)

1. **`text-white` sobre fondo de color/gradiente**: botones, badges de color, headers con gradiente. Se queda.
2. **Colores semánticos de estado (NOM-016)**: operativo=emerald, fuera_servicio=red/rose, mantenimiento=amber, traslado=blue. Si el tono era `-400` y el fondo ahora es claro → subir a `-600/-700` para contraste.
3. **`.qr-label-*`** (etiquetas QR/print) y **SVG de gráficas** con color propio: no tocar.

## Lecciones aprendidas

1. **Migrar 52 archivos en paralelo con dos sesiones simultáneas** (Lote A + Lote B) funcionó, pero requiere contrato estricto (tabla hardcoded→variable) y excepciones bien documentadas para que las sesiones no discrepen.
2. **`text-{color}-400` sobre fondo claro es invisible** — el ajuste a `-600/-700` fue la regla que más se olvidó; `86373f7` se dedicó solo a eso.
3. **`LandingPage.jsx` se quedó dark a propósito** (marketing) — documentar estas excepciones desde el inicio evita retrabajo.
4. **El archivo `MIGRATION-COORD.md` se borró en `95af8ac`** al marcar la migración como completada. Error: un doc de coordinación de una migración grande no debería borrarse al cerrar la tarea. Restaurado el 2026-07-01 desde `51f2a61` con este release notes como contraparte vigente.
