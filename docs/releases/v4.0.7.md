# SIGAB v4.0.7 — 2026-07-04

## Qué cambió
Continuación del barrido de contraste del design system Verde-Blanco IMSS
(`docs/DESIGN-SYSTEM-V4.md`), esta vez sobre el flujo de **Tecnovigilancia /
Eventos Adversos** y el **Centro de Alertas** — módulos marcados como "alta
prioridad, siguiente ciclo" en el backlog dejado por la sesión anterior.

- `EventoAdversoModal.jsx` (reporte NOM-240): botón cerrar (✕), el resumen
  final del paso 3 ("Dispositivo:", "Tipo:") y el botón "Cancelar"/"Anterior"
  usaban `text-white`/`hover:text-white` fijo sobre fondo de tema.
- `EventoDetalleModal.jsx`: botón cerrar (✕) y el valor de "Tipo" en la
  sección Clasificación tenían el mismo problema. El texto "Cargando
  detalles..." se dejó sin tocar porque va sobre un overlay `bg-black/60`
  fijo (no depende del tema, siempre legible).
- `pages/Alertas.jsx`: botón "Marcar todas leídas" y el texto del mensaje
  de cada alerta usaban `text-white` fijo sobre `bg-[var(--content-surface)]`.

Todos se corrigieron a `var(--content-text)` / `hover:text-[var(--content-text)]`,
siguiendo el mismo patrón usado en los ciclos previos (Dashboard, Equipos,
Mapa de Activos, Órdenes). Los badges y botones con fondo sólido (rojo,
azul, emerald, amarillo, púrpura, naranja) se dejaron igual — ese uso de
`text-white` es correcto porque el fondo no cambia con el tema.

## Por qué
Directiva de Gustavo (2026-07-03): dejar la v4.0 lista para producción con
la paleta Stitch funcional. El backlog de contraste de
`docs/DESIGN-SYSTEM-V4.md` prioriza estos dos módulos por ser flujo core
del piloto (reporte de eventos adversos NOM-240 y alertas del sistema).

## Qué verificar
1. Tecnovigilancia → "Reportar Evento Adverso": llegar al paso 3 (resumen)
   en tema "Azul IMSS (claro)" o "Verde SIGAH (claro)" — "Dispositivo:" y
   "Tipo:" deben verse legibles, igual que el botón "Cancelar"/"Anterior".
2. Tecnovigilancia: abrir el detalle de un evento existente en modo claro —
   el botón ✕ y el valor de "Tipo" en Clasificación deben verse.
3. Centro de Alertas en modo claro: el botón "Marcar todas leídas" y el
   texto de cada alerta deben ser legibles, no invisibles.

## Cómo revertir
```
git revert <commit-de-esta-version>
```
sobre `v4.0/piloto-clinica-1`. Cambio solo de clases JSX, sin lógica ni
llamadas a la API — revert seguro sin rollback de base de datos.
