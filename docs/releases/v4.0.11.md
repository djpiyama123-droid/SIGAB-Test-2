# SIGAB v4.0.11 — 2026-07-05

## Qué cambió
Continuación del barrido de contraste del design system Verde-Blanco IMSS
(`docs/DESIGN-SYSTEM-V4.md`). Este ciclo se planeó en paralelo al ciclo
automático del loop de la ThinkCentre (`loop-thinkcentre`): mientras esta
sesión trabajaba, ese loop pusheó directo a `v4.0/piloto-clinica-1` sus
propios ciclos v4.0.9 (`pages/Copilot.jsx`, commit `590ebef`) y v4.0.10
(4 componentes transversales, commit `7405a4c`) — ambos con una corrección
de `Copilot.jsx` esencialmente idéntica a la que esta sesión había hecho de
forma independiente. Al reconciliar (rebase de esta rama sobre la base
actualizada) se descartó el commit propio de `Copilot.jsx` por estar
duplicado y superado por la versión ya en `v4.0/piloto-clinica-1` (usa
`bg-[var(--content-surface)]` y quita `prose-invert`, ligeramente mejor que
el fix original de esta sesión). Los otros dos módulos de esta sesión —
`pages/QRBatch.jsx` y `pages/Analitica.jsx` — no fueron tocados por ninguno
de los dos ciclos del loop, así que se mantienen intactos.

- **`pages/QRBatch.jsx`** (el más afectado del backlog original, 8 bugs):
  las 3 píldoras de la barra de estadísticas, el panel de Vista Previa y la
  barra de herramientas usaban `bg-slate-800/*` fijo mezclado con texto de
  tokens de tema — ahora `bg-[var(--content-surface)]`. El input de
  búsqueda y el select de área tenían `text-white` fijo sobre un fondo que
  en temas claros es blanco (`bg-[var(--content-bg)]`) — el texto escrito
  era invisible. Los botones "Vista Previa", "Seleccionar visibles" y
  limpiar búsqueda (✕) tenían el mismo problema. Las tarjetas de selección
  de equipo usaban `bg-slate-800/40` + texto blanco fijo; se migraron al
  mismo patrón que `EquipoCard.jsx` (`bg-[var(--content-surface)]` +
  `text-[var(--content-text)]`), con el estado "seleccionado" usando un
  acento translúcido (`bg-purple-500/10`).
- **`pages/Analitica.jsx`**: el título "Ingeniería Clínica 4.0" y los
  valores numéricos de 3 de los 4 KPIs principales (Disponibilidad Global,
  MTBF Promedio, MTTR Promedio) usaban `text-white` fijo sobre tarjetas con
  fondo de tema. Las columnas MTBF/MTTR de la tabla del Heatmap de
  Fiabilidad tenían el mismo problema, y el hover de fila
  (`hover:bg-slate-800/40`) mezclaba fondo fijo oscuro con texto de tema
  (oscuro en modo claro) — ahora `hover:bg-[var(--content-border)]/30`.

Los badges/CTAs con fondo sólido (rojo, azul, púrpura, ámbar, emerald) y las
etiquetas QR imprimibles (que emulan papel físico, `bg-white` intencional)
se dejaron igual — ese uso de color fijo es correcto porque no depende del
tema de fondo.

**No incluido en este ciclo** (queda para el siguiente): `pages/Reportes.jsx`
(siguiente en "Secundaria") y `OCRScannerModal.jsx`/`TripleValidationModal.jsx`
(únicos que quedan pendientes de "Modales/componentes transversales" tras el
v4.0.10 del loop).

## Por qué
Directiva de Gustavo (2026-07-03): dejar la v4.0 lista para producción con
la paleta Stitch funcional en los 3 temas. El backlog de contraste de
`docs/DESIGN-SYSTEM-V4.md` (barrido 2026-07-04) documenta 25 archivos con
bugs reales confirmados; este ciclo avanza el siguiente tramo priorizado sin
duplicar el trabajo que el loop de la ThinkCentre ya había hecho en
paralelo sobre `Copilot.jsx` y los componentes transversales.

## Cómo revertir
```
git revert <commit-de-esta-version>
```
sobre `v4.0/piloto-clinica-1`. Cambio solo de clases JSX (colores), sin
lógica ni llamadas a la API — revert seguro sin rollback de base de datos.
